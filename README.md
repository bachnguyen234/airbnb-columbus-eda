# Exploratory Data Analysis of Columbus Airbnb Listings

This project explores **Airbnb listings in the Columbus, Ohio area** using Python and pandas. The analysis combines data cleaning, exploratory statistics, and visualization to investigate patterns in listing characteristics, pricing, and location.

## Analysis

The project includes:

- Cleaning and transforming Airbnb listing data
- Exploratory analysis of listing characteristics and pricing
- Descriptive statistics and grouped summaries
- Analysis of missing and inconsistent data
- Text-based feature extraction from listing information
- Data visualization using multiple plot types
- Geographic exploration of listings and nearby landmarks

## Methods

**Data Analysis**
- Data cleaning and transformation
- Descriptive statistics
- Group-by aggregation
- Feature engineering

**Visualization**
- Histograms
- Scatter plots
- Box plots
- Geographic visualization

## Tools

- Python
- pandas
- NumPy
- matplotlib
- seaborn
- Jupyter Notebook

## Dataset

The project uses Airbnb listing data from the **Columbus, Ohio area**, along with a supplementary dataset containing Columbus-area landmarks.
